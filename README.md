# CustomClicker

I'm building a Windows auto clicker using Java and JavaFX. There are a lot of sketchy auto clickers floating around online, so I wanted to make my own and know exactly what's running on my computer.

## Supported Versions

- Windows 10 (64-bit)
- Windows 11 (64-bit)

## Status

Active development. Core clicking functionality, configurable hotkeys, profiles, and persistence are implemented. Currently working on settings functionality and finalizing the application for release.
